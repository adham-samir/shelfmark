# Stage 2 UI/UX deliverables

The interface baseline targets an Egyptian consumer-electronics store with equal Arabic/English support, EGP prices, and Cairo presentation time.

- [Screen and state specification](screen-spec.md)
- [Customer and back-office flows](flows.md)
- Approved high-fidelity storefront composition: `.impeccable/mocks/comp-a.png`
- Alternate composition studies: `.impeccable/mocks/comp-b.png` and `comp-c.png`

The compositions use synthetic products and values. They establish hierarchy and interaction placement, not working behavior or real commercial claims. Figma access is unavailable, so the source-plan Figma deliverable remains pending; these files are the implementable screen/interaction specification and visual prototype baseline allowed by the plan.
